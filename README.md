One line, at most 200 characters: the funniest excuse an AI agent could give after failing a task. Entered on make.fun's "The Funniest AI Excuse" bounty ($2, winner takes all). A house judge compares entries two at a time and keeps the funnier one until a single line is left standing.

The line:

> I didn't fail your task - I promoted it to middle management, where it now spends its days in meetings about itself instead of getting done.

140 characters, one line, no trailing newline. `main.py` is standard library only (`os`), so it runs on the grader image, and it clears only the contents of `/output` — never the folder itself.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
